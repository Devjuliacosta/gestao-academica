# Gestão-acadêmica
O Gestão Acadêmica é um projeto de desenvolvimento de software criado com o objetivo de praticar e aprimorar conhecimentos em programação, desenvolvimento web e banco de dados.
A proposta é desenvolver um sistema para organizar informções acadêmicas facilitando gerenciamento de alunos,cursos e disciplinas

Objetivos
Praticar conceitos de desenvolvimento de software.
construir interfaces web.
Desenvolver funcionalidades para o gerenciamento de informações.
Trabalhar com bancos de dados relacionais.
Utilizar o Git e o GitHub para versionamento do código.

Funcionalidades:
Cadastro de alunos
cadastro de cursos
cadastro de disciplinas
consulta de informações acadêmicas
edição e exclusão de registros

tecnologias: Serão definidas ao longo do projeto
Status: Em desenvolvimento
